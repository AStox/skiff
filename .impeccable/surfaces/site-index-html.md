Scope: single-page landing site for the browser (working name Skiff, shown as "Untitled Browser"), mode Persuade, hosted on GitHub Pages from `site/`.

Audience: Mac users losing Arc on December 22, 2026, and tinkerers who want to own their browser. Action: download the alpha DMG. Proof: real renders of the eight bundled shells, the command bar, the agent grant model, honest limits.

## Direction contract

THESIS: The browser is a set of parts you can swap, and the page proves it by swapping them in front of you. Refuses the category default of a dark hero with one cropped screenshot and a three-column feature grid.

OWN-WORLD: Drenched single-colour ground that changes with the selected shell, from Allo's saturated palette; near-black ink; hairline 1.5px black rules dividing the page into a strict grid; Allo variable at 800 to 900 for display, 400 to 500 for text; system mono only for commands and code; black bands for emphasis.

STORY: Visitor sees the real browser, flips through eight interfaces, learns Arc data comes along, sees what agents can and cannot touch, reads the honest limits, downloads.

FIRST VIEWPORT: Top bar (wordmark, alpha tag, links, download). Left: huge Allo headline "A browser you can take apart." with subhead and a black download button plus Intel link and version line. Right: real screenshot in a frame with a row of shell names above it; picking one swaps the image and re-inks the page.

FORM: user-pinned references (neki.dev grid and drench, concordance.co colour field, lazybones live demo, Allo type). seed: eb06a39db4ff872e

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
